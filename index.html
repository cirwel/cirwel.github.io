Repositories & releases

UNITARES

Self-hosted infrastructure for identity, evidence, memory, longitudinal state, review, policy, recovery, leases, handoffs, and coordination. Exposes MCP, REST, an SDK, and operator surfaces.

Repository · Paper · PyPI · Archived release

Anima

A Raspberry Pi sensor system used to test longitudinal telemetry, continuity, and state-estimation machinery against a physically situated process. Its traces support the digital-proprioception work and the published datasets.

Repository

UNITARES Resident

Conversation loops, provider adapters, tools, scheduling, and queues built on the public UNITARES contract. The resident is optional; a custom runtime can use the SDK directly.

Repository

Host adapters & plugin

Thin integrations that connect Claude Code, Codex, Hermes, and other hosts to UNITARES check-ins, review, memory, and policy surfaces without moving the agent loop into Core.
