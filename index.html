Kenny Wang · CIRWEL Systems · independent research

Runtime infrastructure for persistent AI agents.

I build systems for agent work that spans sessions, restarts, and handoffs. The main project, UNITARES, keeps identity, evidence, memory, runtime state, review, and coordination accountable across those boundaries.

Persistent describes continuity of the work and its accountable record—not a claim that one process runs forever. UNITARES sits alongside model providers and agent frameworks rather than replacing them.

04

Experiments

The stack is also a research apparatus. These are the questions that matter more than raw event volume.

Can runtime state discriminate?Do recorded operational patterns meaningfully differ across agents or workload classes?
Can it predict?Does prior state anticipate meaningful outcomes better than simpler baselines? This remains unresolved.
Does acting on it help?Intervention benefit is not established. External or adversarial evaluation is still needed.
